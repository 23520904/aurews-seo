AUDIT

Critical Gaps Found in Your Codebase

🚨 Zero Test Coverage Your package.json has no test runner installed (no vitest, no jest, no playwright). The CI runs npm run test || true — the || true means any test failure is silently ignored and deployments proceed. This is a production risk.
⚠️ Unpinned Action Versions aquasecurity/trivy-action@master and vercel/action@master are unpinned — a supply-chain attack can inject malicious code on any run. Always pin to a specific version tag or SHA.
⚠️ No Database Migration in Deployment Your Prisma schema changes are never automatically migrated in production. A deploy with schema changes but no migration will cause runtime crashes on Neon DB.
ℹ️ No Preview Deployments for Pull Requests You have 4 open PRs. None trigger a Vercel preview deployment with automated tests. Preview URLs let you catch visual regressions before merging.
ℹ️ No Core Web Vitals Guard for SEO aurews.id.vn is an SEO-first news platform. A Lighthouse CI check blocking deploys on CWV regression is standard practice for news sites competing in Google News.

// Level 1: Unit test — news-sitemap 48h fallback logic
import { describe, it, expect, vi, beforeEach } from 'vitest'
import { buildNewsSitemap } from '@/lib/sitemap-builder'

const mockRecentPost = {
  id: '1', slug: 'ai-news-today', title: 'AI News Today',
  createdAt: new Date(), status: 'PUBLISHED'
}
const mockOldPost = {
  ...mockRecentPost, id: '2',
  createdAt: new Date(Date.now() - 72 * 3600000) // 72h ago
}

describe('News Sitemap Builder', () => {
  it('includes posts published within 48 hours', async () => {
    const xml = await buildNewsSitemap([mockRecentPost])
    expect(xml).toContain('ai-news-today')
    expect(xml).toContain('<news:news>')
  })

  it('falls back to 5 latest when no recent posts exist', async () => {
    // No posts within 48h — should use fallback
    const xml = await buildNewsSitemap([], [mockOldPost])
    expect(xml).toContain('ai-news-today') // fallback included
    expect(xml).not.toMatch(/<urlset[^>]*>\s*<\/urlset>/) // not empty
  })

  it('returns valid XML structure', async () => {
    const xml = await buildNewsSitemap([mockRecentPost])
    expect(xml).toContain('<?xml version="1.0"')
    expect(xml).toContain('xmlns:news=')
  })
})

import { test, expect } from '@playwright/test'

test.describe('Article Page — SEO critical paths', () => {
  test('has JSON-LD NewsArticle schema', async ({ page }) => {
    await page.goto('/article/ai-news-2026-the-hardware-revolution')

    const ld = await page.locator('script[type="application/ld+json"]').first().textContent()
    const schema = JSON.parse(ld!)
    expect(schema['@type']).toBe('NewsArticle')
    expect(schema.mainEntityOfPage).toContain('aurews.id.vn')
  })

  test('canonical URL is production domain', async ({ page }) => {
    await page.goto('/article/ai-news-2026-the-hardware-revolution')
    const canonical = await page.locator('link[rel="canonical"]').getAttribute('href')
    expect(canonical).toMatch(/^https:\/\/(www\.)?aurews\.id\.vn/)

  test('og:image is a Cloudinary URL', async ({ page }) => {
    await page.goto('/article/ai-news-2026-the-hardware-revolution')
    const ogImg = await page.locator('meta[property="og:image"]').getAttribute('content')
    expect(ogImg).toMatch(/cloudinary\.com|res\.cloudinary/)
  })
